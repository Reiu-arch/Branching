# Git Branching Cheat Sheet

## Basic Commands

* 'git init' - initialize current repository into a work directory
* 'git add "filename"' -gets the "filename" ready for a commit
* 'git commit -m "message"' - commits ready'd "filename" with an attached message
## Info Commands

* 'git status' report satatus of working directory
* 'git log' - list commit history of local history
* 'git log --oneline' list commit history (compact hiscory)
